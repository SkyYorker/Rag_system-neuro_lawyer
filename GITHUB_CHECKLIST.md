# ✅ Чеклист для публикации на GitHub

## 📦 Что загружать на GitHub

### ✅ Обязательные файлы:

1. **`Практическая_работа_2_ipynb_ (2).ipynb`** ⭐
   - Основной блокнот с полной RAG-системой
   - Это главная ценность проекта

2. **`README.md`**
   - Полная документация проекта
   - Инструкции по запуску
   - Описание архитектуры

3. **`requirements.txt`**
   - Все зависимости проекта
   - Нужен для воспроизводимости

4. **`LICENSE`**
   - MIT лицензия
   - Показывает, что проект open-source

5. **`.gitignore`**
   - Исключает секреты, кэши, временные файлы
   - Уже настроен правильно

6. **`docs/`** (вся папка)
   - `architecture.md` - архитектура системы
   - `GPU_CPU_SETUP.md` - настройка GPU/CPU
   - `TROUBLESHOOTING.md` - решение проблем
   - `INSTALL_CELL.md` - ячейка установки
   - `LLAMA_GPU_SETUP.md` - настройка GPU для llama-cpp
   - `HYBRIDGUARD_FIX.md` - исправление HybridGuard

### ❌ НЕ загружать:

- `src/__pycache__/` - кэш Python (уже в .gitignore)
- `tests/` - пустая директория (можно удалить)
- `.env` файлы - секреты (уже в .gitignore)
- `chroma_db_test/` - база данных (уже в .gitignore)
- `*.zip` - архивы (уже в .gitignore)

## 🔧 Что нужно сделать перед публикацией

### 1. Обновить README.md

Замените плейсхолдеры:
- `YOUR_USERNAME` → ваш GitHub username
- `YOUR_REPO_NAME` → название вашего репозитория
- `your.email@example.com` → ваш email
- `Ваше имя` → ваше имя

### 2. Проверить блокнот

- [ ] Все ячейки работают
- [ ] Нет секретов/токенов в коде
- [ ] Есть комментарии и объяснения
- [ ] Структура понятна

### 3. Проверить .gitignore

- [ ] `.env` файлы исключены
- [ ] Кэши исключены
- [ ] База данных исключена
- [ ] Временные файлы исключены

## 📝 Команды для публикации

```bash
# 1. Инициализация (если еще не сделано)
git init

# 2. Добавить все файлы
git add .

# 3. Проверить что будет загружено
git status

# 4. Создать первый коммит
git commit -m "Initial commit: RAG Legal Advisor - портфолио проект"

# 5. Создать репозиторий на GitHub (через веб-интерфейс)
# Название: rag-legal-advisor или rag-neuro-lawyer

# 6. Добавить remote и отправить
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```
